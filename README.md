Inventario IberoTech — aplicación CRUD con **PHP**, **MySQL** y **PDO** (entorno Laragon).

### Archivos principales

| Archivo | Descripción |
|---------|-------------|
| `conexion.php` | Conexión PDO a `diplomado_ibero` |
| `index.php` | Panel CRUD (listar, buscar, crear, editar, borrar) |
| `guardar_producto.php` | Procesamiento de altas y actualizaciones |
| `productos.php` | Listado simple de productos |
| `cotizador.php` | Cotizador en el servidor |

### Requisitos

- Laragon (Apache + MySQL)
- Base de datos `diplomado_ibero` con tabla `productos`

### Acceso local

`http://localhost/Proyecto1/index.php`
